Duewise

A lightweight payment tracking tool for freelancers to manage client projects, record payments, and keep track of outstanding balances.

Goals

- Organize clients and projects in one place.
- Track full and partial payments.
- Automatically calculate outstanding balances.
- Identify upcoming and overdue payments.

Planned Tech Stack

- React
- TypeScript
- Vite
- NestJS and MySQL (planned for the backend)

Status

Planning and initial development.

This project is being built as a personal learning project exploring UI/UX design, frontend development, and full-stack application development.
